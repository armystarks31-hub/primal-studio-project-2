# Start here: GitHub Desktop workflow from class

1. Download and unzip this package on your Mac.
2. Open GitHub Desktop. Choose File > New Repository.
3. Name it primal-studio-project-2. Choose a local path you can find again. Create Repository.
4. Choose Repository > Show in Finder.
5. Copy the CONTENTS of the downloaded primal-studio folder into that repository folder. index.html must be at the top level beside photography.html, barbering.html, css, js, and images.
6. In GitHub Desktop choose Repository > Open in Visual Studio Code.
7. In GitHub Desktop enter the summary “Add Project 2 first draft”, then Commit to main.
8. Click Publish repository. For class access, uncheck “Keep this code private”, then publish.
9. Choose Repository > View on GitHub. Copy that real repository URL for your submission.
10. After every edit: save in VS Code, return to GitHub Desktop, write a summary, Commit to main, then Push origin. Saving alone does not update GitHub.
